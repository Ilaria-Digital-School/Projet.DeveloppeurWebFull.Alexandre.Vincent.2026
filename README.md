Schéma d'enchaînement des maquettes :
    L'utilisateur arrive sur la page d'accueil et peut accéder aux différentes catégories de voyage via le menu principal.

    Le parcours principal est :
    Accueil → Recherche d'offre → Consultation des résultats → Consultation du détail d'une offre → Achat / Réservation.

```text
Accueil
  │
  ├── Hotels
  ├── Flights
  ├── Flight + Hotel
  ├── Self Catering
  ├── Cruises
  ├── Car Rental
  ├── Locations
  ├── Hot Deals
  ├── Blog
  └── Contact

Parcours principal :

Accueil
  ↓
Recherche d'une offre
  ↓
Résultats
  ↓
Détail de l'offre
  ↓
Achat / Réservation
```
